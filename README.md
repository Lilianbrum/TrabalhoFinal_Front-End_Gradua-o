# O Cânone Perene

Site estático desenvolvido como projeto final de front-end. O conteúdo apresenta uma curadoria literária organizada por períodos e temas, com páginas para a curadora, Pré-Modernismo, Oitocentismo, subjetivismo, alienação e contato.

## Como visualizar

Abra `index.html` em um navegador. O projeto usa HTML e CSS, sem etapa de compilação.

## Tecnologias

- HTML
- CSS

> Projeto acadêmico demonstrativo. O formulário e os links devem ser conferidos antes de uso como site publicado.
